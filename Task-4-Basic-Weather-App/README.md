# Task 4 - Basic Weather App

## 📌 Overview

This project is a Basic Weather App developed using Python as part of the Python Programming Internship at Oasis Infobyte.

The application fetches real-time weather information for a user-specified city or ZIP code using the OpenWeatherMap API and displays the weather details through a user-friendly Tkinter interface.

## ✨ Features

- Search weather by city name
- Search weather using ZIP code
- Display current temperature in °C
- Display current temperature in °F
- Display "Feels Like" temperature
- Display humidity percentage
- Display weather condition
- Display wind speed
- Empty location input validation
- City/location not found handling
- Invalid API key handling
- Network connection error handling
- Request timeout handling
- User-friendly graphical interface

## 🛠️ Technologies Used

- Python
- Tkinter
- Requests
- JSON
- python-dotenv
- OpenWeatherMap API
